# OctoFit Tracker 🏃‍♂️

A social fitness app designed to help students stay active and compete with their peers.

## Overview

OctoFit Tracker combines personal fitness tracking with social competition to motivate students to maintain active lifestyles. Users can log workouts, track progress, challenge friends, and climb leaderboards.

## Features (In Development)

- **Activity Tracking**: Log workouts, runs, gym sessions, and sports activities
- **Social Competition**: Challenge friends and see who's the fittest
- **Leaderboards**: Track rankings by activity type, distance, duration, and more
- **Social Feed**: Share achievements and celebrate fitness milestones
- **User Profiles**: Showcase fitness stats and personal records
- **Challenges**: Create and participate in timed fitness challenges
- **Achievement Badges**: Earn badges for completing milestones

## Tech Stack

- **Frontend**: React.js with TypeScript
- **Backend**: Node.js/Express
- **Database**: MongoDB
- **Authentication**: JWT
- **Deployment**: GitHub Pages (frontend), Heroku/Railway (backend)

## Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn
- MongoDB (local or Atlas)
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/SyedFarhanHusain123/OctoFit-Tracker.git
cd OctoFit-Tracker

# Backend setup
cd backend
npm install
npm run dev

# Frontend setup (in another terminal)
cd frontend
npm install
npm start
```
